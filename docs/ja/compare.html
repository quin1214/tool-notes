3 社とも、お試し（弥生は無料体験）では申告書の提出までできません。お試しは画面の使い心地と明細の取り込みを確かめるためのもの、と考えておくのがよさそうです。

スマホだけで申告まで済ませたいなら

  • freee: スマホアプリでも所得税の確定申告書を作れます（一部の機能は Web 版で操作）
  • マネーフォワード: アプリから電子申告できます（マイナンバーカードと、カードを読み取れるスマホが必要）
  • 弥生: 申告書と青色申告決算書の作成にはパソコン（Windows か Mac）が必要です。アプリは日々の入力用です

白色申告なら

白色申告で、なるべく費用をかけたくない場合は、弥生の「やよいの白色申告 オンライン」のフリープランが候補になります。機能がずっと無料で使えます（サポートは Web の FAQ のみ）。

3 つを触ってみて

freee と弥生は、銀行口座やクレジットカードを連携して明細を読み込ませるだけで、自動で仕訳まで進みました。手間はほとんど変わらず、明細の自動仕訳だけで比べるなら、どちらを使ってもよいと感じました。マネーフォワードは、2026 年 11 月 7 日に試したときは夜間メンテナンスと勘定科目の提案の停止が重なっていて、同じ条件では比べられませんでした（詳しくは マネーフォワードのページ）。

そのため、選ぶときに差が出るのは、自動仕訳よりも次のような所だと思います。

  • プランによる機能の違い: 弥生はどのプランも機能が同じなので、迷わずに済みました。freee とマネーフォワードは、消費税の申告ができるかどうかなどがプランで変わります。
  • 簿記を知らなくても進めやすいか: 比較記事や利用者の声では、freee は簿記を知らない人向けの作り、マネーフォワードは簿記を知っている人に使いやすい、という見方が多く見られました。運営者が触った範囲では、ここまでは確かめられていません。
  • サポート: 電話で聞けるのは、freee とマネーフォワードはいちばん上のプランだけ、弥生はベーシックからです。
  • パソコンがあるか: 弥生は申告書の作成にパソコンが必要です。
