# 日本語版: 本人がやること

終わったら `[x]` にして日付を書く。条件（報酬・Cookie・禁止事項）がわかったら Claude に伝えるか、`CLAUDE.md` の日本語版の表に書く。

## 1. ASP の登録（先にやる）
- [ ] もしもアフィリエイトに登録する。媒体には GitHub Pages の URL を登録する（ほぼ空のサイトのまま申し込むか、`docs/ja/` を作り込んで公開してから申し込むかを先に決める）
- [ ] もしもで「会計 freee」に提携申請する
- [ ] もしもで「マネーフォワード クラウド確定申告」に提携申請する
- [ ] A8.net（またはバリューコマース）に登録する
- [ ] A8.net で「やよいの青色申告 オンライン」に提携申請する

## 2. 提携後に確認して Claude に渡すもの（案件ごと）
- 報酬額と成果条件（無料登録か有料契約か、対象外になる人）
- Cookie の期間
- 禁止事項（検索広告、SNS からの直リンク、自己アフィリエイト、表現の制限）
- 広告リンク（テキストリンク）

## 3. 流入元の準備
- [ ] X のアカウントを決める（既存の Tool Notes を使う／新しく作る）
- [ ] Pinterest に日本語用のボードを作る

## 4. 公開の判断
